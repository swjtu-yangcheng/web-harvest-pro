# 来源资格与结论强度（定权 · 定信 · 定述）

## 何时读本文

任务要**下判断**时读：市场规模/份额、企业实情、技术能力、政策影响、成本可行性，以及任何要写进交付物的数字或趋势结论。

纯抓取、纯文档搬运、纯文献著录**不需要**读本文——那两类分别看 CRAWLING.md 与 ACADEMIC.md。

## 三步

| 步 | 要回答的问题 | 失效后果 |
|---|---|---|
| **定权** | 谁有资格说这句话 | 用错来源，后面全错 |
| **定信** | 该信几分，冲突怎么处理 | 把结构性偏差当随机误差 |
| **定述** | 报告里怎么交代不确定性 | 读者无从复核，结论不可引用 |

## 1 定权：资格 = 一线数据获取权 × 利益独立性

两维缺一样，来源就只能当线索。**载体类型不等于资格**：官方域名只说明它能拿到一手材料，不说明它在**自身利益相关的指标**上有资格。

| 一线数据权 | 利益独立性 | 判定 | 典型 |
|---|---|---|---|
| 有 | 独立 | 合格说话人 | 统计局、海关、审计财报、法院判决、第三方复现 |
| 有 | 相关 | 可用，必须去偏并标注利益关系 | 品牌自报销量、厂商自评 benchmark、行业协会统计 |
| 无 | 独立 | 可用，明确标“估算/推断” | 券商测算、咨询公司、学者二次建模 |
| 无 | 相关 | 只能当线索，不得作结论依据 | 通稿转载、软文、带货测评、AI 摘要 |

**硬规则**：品牌/机构在**自述类数据**（自家销量、份额、性能、安全记录）上一律按 C 级处理，不因“官方”升 A；只有独立方复算或法定披露才可升格。

### 按“你要什么”找合格说话人

| 要的判断 | 合格说话人 | 看着权威、其实没资格 |
|---|---|---|
| 法定事实（收入、产量、判决、专利） | 审计财报、统计局、海关、判决书、专利原文 | 券商摘要、百科、AI 摘要 |
| 市场结构与份额 | 披露样本与口径的机构 | 通稿“据估计”、品牌自报“市占率第一” |
| 企业内部实情 | 招股书风险因素、诉讼文件、离职员工、招聘 JD | 官网 About、发布会 PPT、公关访谈 |
| 技术能否做到 | 有代码+数据+第三方复现 | 厂商 demo、媒体标题、KOL 实测 |
| 技术成熟度 | 量产数据、良率、专利族、TRL 评估 | 发布会“已量产”、路线图 |
| 成本与规模可行 | BOM 拆解、设备出货、供应链交期、招聘岗位 | 券商 TAM 测算、渗透率曲线 |
| 人的真实偏好 | 有样本量的问卷、一手深访 | 平台评分、评论区、社群情绪 |

## 2 定信：三条硬动作

1. **冲突不取平均**。两源不一致时先找差异成因（口径、版本、样本），再决定是否可比。取中间值会把结构性偏差伪装成随机误差，比用错一侧更危险。
   案例：帝舵 2024 年同一机构两版报告 3.60 vs 4.50 亿瑞郎（+25% 回溯修订）；泰格豪雅 2018 年两家机构 8.10 vs 9.85 亿（差 18%）。两者都不能平均。
2. **同源识别**。转载同一通稿、引用同一数据库、出自同一作者团队、同一机构的不同语言版本，都算**一个源**，不构成交叉验证。
3. **负面优先**。失败案例、撤稿、issue 报错、良率爬坡、诉讼、岗位下架、客户流失——负面信息获取成本高，信噪比远高于正面信息。只看到正面材料时，先假设检索存在偏斜。

## 3 口径归一（本文件最容易出事的一节）

同一名词在不同来源指不同东西。**先定义再使用**，并在交付物里写出定义。

| 陷阱 | 常见混用 |
|---|---|
| 量的口径 | 销量 / 出货量 / 零售量 / 激活量 |
| 价的口径 | 批发价（manufacturer turnover）/ 零售价 / 建议零售价 |
| 金额口径 | 含税 / 不含税、GMV / 收入、签单 / 确认收入 |
| 时间口径 | 财年 / 自然年、报告年度 / 数据年度（2026 年版报告写的是 2025 年数据） |
| 地域口径 | 大中华区 / 中国内地 / 含港澳台、生产地 / 消费地 |

三条处置规则：

- **版本回溯**：同一机构次年报告会重述历史数。跨年序列必须统一到同一版本，或显式标注“混合版本”。
- **跨源不算增速**：来源体系不同的两个年份之间，只做方向判断，不做幅度比较（“上升/下降”可用，“+96%”不可用）。
- **缺口留空，不插值**。某年确实没有可靠数据时，留空并写明为何留空。插值出来的点会被下游当作观测值继续引用，错误被放大且无法追溯。

## 4 定述：条件句 + 有效期 + 降级声明

结论强度分三档，交付物必须显式落到其中一档：

| 档 | 允许的表述 |
|---|---|
| 可算幅度 | “A 比 B 高 N%”（要求：同口径、同版本、双方均 ≥B 级） |
| 只看方向 | “A 高于 B，幅度不可比”（跨源、跨版本、含 C 级数据时） |
| 仅作线索 | “有资料显示……，未核验”（单一 D 级来源） |

模板（可直接套用）：

> 该结论依据〔来源，级别〕，口径为〔定义〕，与〔另一来源〕相差〔N%〕，差异主要源于〔原因〕；因此此处**只做方向判断，不做幅度比较**。

> 现有证据支持：在〔数据集/工况/规模〕条件下，方法 A 相对基线 B 在〔指标〕上有〔幅度〕提升，证据级别〔B：单一团队、未独立复现〕；超出该条件无数据。**该判断有效期约 12 个月**——若期内出现公开复现或规模化落地，需重新评估。

科技类结论必须带**有效期**：技术判断会过期，写到期日等于替读者守住下次复核的时间点。

## 5 科技与前沿判断专项

### 5.1 载体领先时间（越靠左越早能知道）

追踪前沿时，把精力放在左侧信号；“综述/教科书”出现时该方向通常已进入工程化。

| 载体 | 相对“工程可用” | 读什么 |
|---|---|---|
| 专利与学术基金 | 约提前 33 月 | 谁在投钱、往哪个方向投 |
| 招聘岗位（JD） | 约提前 18 月 | 需要什么新技能 → 在建什么 |
| 设备与材料出货 | 约提前 15 月 | 上游产能 → 下游量产时点 |
| 代码仓库与 issue | 约提前 9 月 | 实际能力边界、别人踩到的坑 |
| 预印本 | 约提前 8 月 | 最新方法，未评议 |
| 顶会接收名单 | 约提前 4 月 | 已被同行认可的选题 |
| 期刊正式发表 | 约提前 1 月 | 定稿版本、审稿人质疑 |
| 综述与教科书 | 滞后约 10 月 | 只用于建立背景，不作前沿依据 |

数值为经验区间，学科差异大，不当作精确统计。

### 5.2 科技领域的资格判据：谁复现过

载体类型之外，多问一句“跑通了吗”。A 级证据是**第三方独立复现**，不是被引用次数。

- 自评 SOTA → C 级；独立榜单 + 公开代码 → 可升 B；第三方在公开库上复现 → A。
- **SOTA 三查**：测试集是否进过训练集；是否只在自家数据分布上比；指标是否被换过。看它敢不敢上公开榜单，以及榜单前几名是否共用同一批数据。
- **工程可用 ≠ 榜单第一**。工程要的是 Pareto（精度、成本、可解释、可维护同时可接受），追踪进展应追“在什么约束下达到什么”，而不是追排名。
- **术语通胀**：同一热词在不同学科指向不同对象（扩散模型的“扩散”与岩土“氯离子扩散”）。先做消歧探针，给操作性定义，再统计数量——否则“进展迅猛”是统计幻觉。详见 RESEARCH.md 消歧探针节。
